# Express TypeScript 7

API REST con Express 5, TypeScript 7 y Drizzle ORM.

## Stack

- Node.js 24
- TypeScript 7
- Express 5
- Drizzle ORM
- Zod 4
- Biome

## Inicio rápido

```bash
pnpm install
pnpm dev
```

## Scripts

```bash
pnpm dev          # desarrollo con hot reload
pnpm typecheck    # validación de tipos
pnpm build        # typecheck + bundle con esbuild
pnpm preview      # ejecuta dist/index.js
```
